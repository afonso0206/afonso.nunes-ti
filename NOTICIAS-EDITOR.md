# Editor de atualizações profissionais

O site usa `dados/noticias.json` como fonte das atualizações.

## Editor local

Abra no computador com XAMPP:

`http://localhost/afonso-nunes-ti/tools/editor-noticias.html`

O editor funciona somente em `localhost`/`127.0.0.1`. No GitHub Pages ele fica bloqueado.

### Fluxo de publicação

1. Abra o editor local.
2. Adicione, edite ou exclua atualizações.
3. Clique em **Baixar noticias.json**.
4. Substitua `dados/noticias.json` no projeto pelo arquivo baixado.
5. Teste localmente `noticias.html`.
6. Faça commit e push pelo GitHub Desktop.
7. O GitHub Pages publica automaticamente.

Nenhuma senha, token ou credencial é necessária no editor.
